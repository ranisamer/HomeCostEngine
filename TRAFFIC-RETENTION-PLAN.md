# Useful repeat visits: 90-day execution plan

Updated October 8, 2026. Goal: genuine U.S. organic clicks, useful calculator sessions, consented subscriptions and return visits. Advertising clicks must arise from genuine interest; never request, reward or simulate them.

## Live first step

Connect a calculator to a relevant free workbook, requested download email and a self-guided sequence of useful tool links. Keep marketing consent optional and unchecked. Provider failures must not be described as successful subscriptions. Public download fallback keeps the resource useful when delivery fails.

## Days 1-30: quality and measurement

- Continue one primary canonical improvement per daily SEO run. Use newest successful U.S. Web final GSC artifact; preserve 14-day substantive-update cooldown unless a concrete bug or new evidence applies.
- Prioritize existing query-page opportunities and useful tool workflows over article count. Repair thin answers, examples, exclusions and internal links.
- Establish a dated weekly report: U.S. clicks, impressions, CTR at comparable positions and period dates. Indexing claims need separate evidence.
- Where authorized analytics supports it, measure workbook-link use, calculator completion and return visits. Do not invent engagement from GSC impressions. Do not transmit emails or detailed calculator inputs to analytics.
- Test the delivery and opt-in path. Do not claim an email reached an inbox from a provider acceptance response alone.

## Days 31-60: deepen and distribute

- Expand distinct questions within the useful existing clusters. Add contextual inbound links and a reason to use the next tool.
- Prepare one short tutorial and one useful social excerpt per substantive improvement. External posts, paid ads and outreach remain subject to specific authorization and connected accounts.
- Test paid acquisition only with an approved budget and quality landing page. Optimize for a useful subscriber or tool action, not AdSense-click arbitrage. No guaranteed CPA, traffic or profit forecast.
- Send a weekly learning message only to the opted-in list after the email workflow and unsubscribe handling have been verified.

## Days 61-90: act on actual outcomes

- Compare completed reporting windows. Expand pages and channels that bring useful organic clicks and repeat tool use; investigate weak intent and consolidate overlaps.
- Improve titles only with adequate impressions and intent evidence. Avoid repeated retitling from a tiny position sample.
- Refresh the workbook when underlying methods or tools change, not merely to change the date.

## Brevo sequence prepared, not activated

The site requests one transactional download email. Timed marketing automation is not active merely because a contact joined BREVO_LIST_ID. Brevo account access is required to configure and verify enrollment, delays, unsubscribe suppression and re-entry rules. No sender credentials belong in this repository.

Use only separate marketing opt-ins. Do not enroll every report requester or every existing contact. Do not resend the course when a subscribed user requests another download. Preserve existing unsubscribes; test on an owner-authorized test address before activation. If the existing list serves another purpose, create a dedicated consented learning list rather than reusing its members indiscriminately.

Proposed sequence: immediate requested workbook (transactional), then optional learning messages after 2, 4 and 7 days. Weekly updates should each teach one distinct decision and link to a relevant tool. Each marketing template needs Brevo's working unsubscribe link and verified sender identity.

## Weekly operating rule

Record the page, intent, measured evidence, new value, links, validation, publication commit and next action in CONTENT-SEO-ROADMAP.md. The existing daily SEO schedule remains unchanged. Email and social distribution are not represented as running until their integrations are configured and validated.
